# AudioHub

**Маршрутизация звука по приложениям в macOS — на выходы Mac, колонки Chromecast и AirPlay.**

[English](README.md)

AudioHub живёт в строке меню и позволяет для каждого приложения выбрать, куда идёт его звук:
музыка — на Chromecast, интернет-радио — на AirPlay-колонку, системные звуки остаются на
мониторе. Может даже собрать стереопару из двух колонок *разных* протоколов.

Без виртуальных аудиодрайверов и расширений ядра: используются перехватчики звука процессов
(process taps) из Core Audio, которые есть в macOS начиная с 14.2.

## Возможности

- **Звук отдельно для каждого приложения** — для любого, которое играет:
  - выходы этого Mac (HDMI/DisplayPort, аналоговые, USB…)
  - колонки **Chromecast / Google Cast**
  - колонки **AirPlay** (RAOP без шифрования; работает со многими колонками AirPlay 2)
- На исходном выходе приложение при этом замолкает.
- Вспомогательные процессы собираются под своим приложением (вкладки браузера, Electron, WebKit в Safari).
- **Громкость колонки**: для сетевых колонок ползунок управляет громкостью самой колонки.
- **Общая громкость и «без звука»** для всего, что ведёт AudioHub.
- **Запоминает маршруты** и включает их снова, когда приложение начинает играть.
- **Стереопара из разных протоколов**: левый канал на одну колонку, правый на другую,
  с линией задержки и щелчками для настройки на слух.
- Приложение в строке меню и режим командной строки.
- Английский, русский и украинский языки.

## Требования

- macOS 14.2 или новее (проверено на macOS 26)
- Command Line Tools (`xcode-select --install`). Полный Xcode не нужен.

## Установка

```bash
git clone <этот репозиторий>
cd AudioHub
scripts/make-signing-cert.sh   # один раз, см. «Разрешения»
scripts/install.sh             # собрать и скопировать в «Программы»
```

При первом использовании macOS попросит два разрешения:

1. **Запись системного звука**: *Системные настройки → Конфиденциальность и безопасность →
   Запись экрана и системного звука → Только системный звук*. Если AudioHub там нет, добавь его кнопкой **+**.
2. **Локальная сеть** — чтобы находить колонки и передавать на них звук.

Автозапуск: *Системные настройки → Основные → Объекты входа → +* → AudioHub.

### Разрешения и подпись

macOS запоминает разрешения по подписи кода. Сборка с ad-hoc подписью после каждой пересборки
для системы — новое приложение, и macOS молча отзывает перехват звука: приложение «работает»,
но записывает тишину. `scripts/make-signing-cert.sh` создаёт в связке ключей самоподписанный
сертификат *AudioHub Local Signing*; `build.sh` подписывает им, если он есть, и выданное один
раз разрешение переживает пересборки. Сертификат больше ни для чего не используется, его можно
удалить в «Связке ключей».

## Использование

Нажми на иконку колонки в строке меню. У играющих приложений — зелёная волна. Справа от
приложения выбери, куда отправлять звук; ползунок под ним — громкость.

**Задержка:** сетевые колонки играют с опозданием примерно на 2 с (AirPlay) и 2–9 с
(Chromecast). Для музыки нормально, для видео — нет.

### Стереопара

1. Разверни внизу меню **«Стереопара»** и выбери левую и правую колонки.
2. У нужного приложения выбери **«Стереопара»**.
3. Включи **«Щелчки для настройки»**: каждую секунду щелчок, каждые 10 секунд длинный гудок.
   Сначала совмести гудки кнопками `« »` (шаг 100 мс), потом щелчки кнопками `‹ ›` (10 мс).
4. Выключи щелчки и выровняй громкости.

Chromecast сам решает, сколько держать в буфере, а у колонок разные часы, поэтому синхронизация
может уплывать — после паузы или подгрузки проверь её щелчками.

### Командная строка

```bash
AUDIOHUB=/Applications/AudioHub.app/Contents/MacOS/audiohub
$AUDIOHUB list                        # приложения со звуком и выходы Mac
$AUDIOHUB speakers                    # колонки Chromecast и AirPlay
$AUDIOHUB route Spotify=cast:Bedroom Music=airplay:Kitchen
```

Если macOS не даёт голому бинарнику из терминала перехват или доступ к сети, запускай через
`run.sh` — он стартует приложение целиком.

## Ограничения

- Колонки AirPlay, требующие сопряжения или шифрования (например, HomePod), не поддерживаются.
- Задержку Chromecast задаёт сама колонка, уменьшить её со стороны отправителя нельзя.
- Веб-звук Safari идёт из процесса WebKit, общего для всех приложений на WebKit.
- Если у Mac два сетевых интерфейса в одной подсети, AudioHub пробует их по очереди.

Как это устроено — в [README.md](README.md#how-it-works).
